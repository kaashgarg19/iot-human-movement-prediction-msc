# Dataset

The original MSc implementation uses a dataset named `iotdata.csv`.

The original dataset is approximately 61 MB and is not stored directly in this repository. The dataset was used locally by the original MSc implementation and is not redistributed here.

The original code in [../code/Aman.py](../code/Aman.py) expects the file to be available locally as:

`iotdata.csv`

The repository contains the original MSc code and dissertation; the dataset itself is kept separate.
